SmartHome v8.1 — History/PostgreSQL Compatibility Verification
===============================================================

ROOT CAUSE FIXED
The deployed History page failed with:
    KeyError: 0

The failing code was:
    conn.execute("SELECT COUNT(*) FROM events").fetchone()[0]

On PostgreSQL/Neon the application uses psycopg's dict_row factory, so
fetchone() returns a mapping rather than a positional tuple. The History
statistics code now uses named columns and works consistently with SQLite
and PostgreSQL/Neon.

REGRESSION PROTECTION
Added a regression test simulating PostgreSQL-style dictionary rows and
verifying get_stats() returns the expected values.
